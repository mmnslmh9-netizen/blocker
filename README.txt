חוסם תכנים - אפליקציית אנדרואיד

בנייה בלי מחשב (GitHub, חינם):
1. צור חשבון ב-github.com ומאגר חדש (New repository).
2. העלה את כל תוכן התיקייה (Add file > Upload files). חשוב שהתיקייה .github תעלה גם.
3. כנס ללשונית Actions, בחר Build APK, והמתן 3-5 דקות.
4. בסוף הרצה פתח אותה והורד מ-Artifacts את chosem-apk. בפנים app-debug.apk.
5. התקן את הקובץ בטלפון (אפשר "התקנה ממקורות לא ידועים").

בנייה באנדרואיד סטודיו: File > Open על התיקייה, ואז Build > Build APK.

הפעלה בטלפון:
1. פתח "חוסם תכנים" ולחץ "הפעל את שירות החסימה".
2. בהגדרות הנגישות בחר "חוסם תכנים" והפעל.
   באנדרואיד 13 ומעלה, אם הכפתור אפור: הגדרות > אפליקציות > חוסם תכנים > שלוש נקודות > "אפשר הגדרות מוגבלות". ואז חזור.
3. סמן את האפליקציות לחסימה. כל אפליקציה שלא סימנת נפתחת כרגיל.
